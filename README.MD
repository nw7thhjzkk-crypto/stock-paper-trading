# 📈 Stock Paper Trading System

Automated paper trading system for Indian stocks (NIFTY 50) with virtual money.

## 💰 Virtual Capital
- Initial: ₹10,000
- Max position per stock: ₹2,000

## 📊 Strategy
- **RSI (14)** + **Moving Average (20)** combo
- Buy: RSI < 35 AND Price > MA20
- Sell: RSI > 65 OR Price < MA20
- Timeframe: 5-minute candles

## 🚀 Features
- Live paper trading (no real money)
- Mobile-friendly web dashboard
- Google Sheets integration
- Trade history tracking
- Profit/Loss analysis
- Win rate calculation
- Start/Stop/Reset controls

## 📱 Access
- Open the Render URL on any device (iPhone/Android/Desktop)
- Dashboard auto-refreshes every 5 seconds
- Control trading with buttons on dashboard
